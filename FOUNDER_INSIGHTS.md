## Design Language

### Colors
- **Background**: Deep dark blue/black (#0a0a1a approx)
- **Primary text**: Cyan/teal (#00ffff approx)
- **Values/positive**: Green (#00ff00 approx)
- **Prices/accents**: Pink/magenta (#ff00ff approx)
- **Secondary**: White for neutral items
- **Borders**: Subtle cyan glow

### Typography
- Monospace/terminal font throughout
- ALL CAPS for headers and labels
- Consistent sizing hierarchy

### UI Elements
- Bordered sections with subtle glow
- Segmented progress bars (not smooth)
- Table-based layouts with clear columns
- Checkbox and action buttons
- "+ ADD" buttons for user input

### Aesthetic
- Cyberpunk/hacker terminal vibe
- "Mission" and "Scan" terminology (military/sci-fi)
- Data-dense but organized
- Functional over flashy
